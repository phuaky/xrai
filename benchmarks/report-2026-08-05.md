# Performance and quality audit - August 5, 2026

## Data snapshot

- `data/events-x.jsonl`: 11,047 event rows from July 10 through August 5.
- 8,051 unique tweet IDs across all X event kinds.
- 4,998 unique feed-decision tweets.
- Since July 23: 3,532 unique decisions, including 2,483 model decisions,
  83 prefilter decisions, 1,956 shown, and 1,576 hidden.
- X text model I/O since July 23: 3,528 calls, p50 2,265ms, p95 7,314ms.
- Historical feed-decision text was capped at 500 characters. 640 unique
  records hit that exact cap, so long historical tweets are not complete.
  The extension now preserves full expanded tweet and reply text.

## Bottlenecks found

1. Three local requests in flight inflated card latency without meaningful
   throughput improvement.
2. The X and YouTube text models could both remain resident for 30 minutes,
   making platform switches stall on model admission.
3. The optional 30B image model ran 1,626 checks with zero bait verdicts:
   p50 4,847ms, p95 15,966ms, seven calls above 60 seconds, and one 30-minute
   outlier.
4. Recent live traffic exposed false hides from broad prefilter patterns and
   false keeps from a prompt that rewarded specificity outside Kuan's topics.

## Changes

- Serialize local text inference across tabs and platforms.
- Unload the prior rai text model before switching between X and YouTube.
- Reduce content and image queues to one in-flight request.
- Disable the unevaluated image gate by default and fail open after 8 seconds.
- Preserve complete future tweet, reply, image-label, and model-input text.
- Include the author in X model input.
- Add an explicit topic relevance gate and first-party release rule.
- Narrow crypto, engagement-bait, and entertainment prefilter patterns.
- Add reusable live burst benchmarking and stratified audit scripts.
- Make evals load the production keep-alive and context settings.
